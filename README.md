# Food App In Kotlin

A fully functional food delivery application built with Kotlin for Android.

## Overview

This is a feature-rich food delivery application that allows users to browse restaurants, view menus, place orders, track deliveries, and manage their profiles. The app demonstrates modern Android development practices using Kotlin.

## Features

- **User Authentication**: Secure login and registration system
- **Restaurant Discovery**: Browse and search for restaurants 
- **Menu Exploration**: View detailed menu items with descriptions and images
- **Shopping Cart**: Add/remove items, modify quantities, and view order summary
- **Order Placement**: Complete the ordering process with delivery address and payment details
- **Order Tracking**: Real-time updates on order status
- **User Profile**: View and edit personal information
- **Order History**: Access past orders and easily reorder favorites
- **Favorites**: Save your favorite menu items for quick reordering

## Technologies Used

- Kotlin
- Android Jetpack Components
- MVVM Architecture
- LiveData and ViewModel
- Firebase Authentication
- Firebase Firestore
- Glide for image loading
- Material Design components

## Requirements

- **Minimum SDK**: API level 33
- **Target SDK**: API level 35 (Android 15)
- **Gradle Version**: 7.4.0 or higher
- **Kotlin Version**: 1.8.0 or higher
- **Java Compatibility**: Java 17.0.15


## Getting Started

### Prerequisites

- Android Studio Arctic Fox or later
- Android SDK 24 or higher
- Kotlin 1.5.0 or later

### Installation

1. Clone the repository:
```
git clone https://github.com/jaykakadiya7876/final-project.git
```

2. Open the project in Android Studio

3. Sync Gradle files

4. Run the application on an emulator or physical device
